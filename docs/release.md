# xserial 本地发布准备

功能已经具备本地体验与验收入口。本地改动已获授权分批提交；推送、打 tag 和公开发布由用户另行授权。本文提供可以复用的发布材料与首批用户验证流程。

## 构建与检查

```bash
go test ./...
go test -race ./...
make all
make release VERSION=v0.2.0
```

版本号是示例，实际发布时按项目版本选择。release 目标生成 Linux、macOS、Windows 的 amd64 与 arm64 压缩包及 checksums.txt。源码使用 MIT，分发包应包含 LICENSE。

本次本地验收使用 `make release VERSION=preview RELEASE_DIR=./dist/preview`。预览包保存在 `dist/preview/`，没有创建公开版本、tag 或上传文件。

## 演示脚本

录制一个 20 到 30 秒的演示：运行 Demo，发送默认查询，Tab 查看字段；移动到偏移 3 展示大端数值 100 和 CRC 校验；复制或修改命令，再次发送。长版演示增加坏 CRC、分段、粘连响应和离线回放。

`assets/workbench-demo.svg` 是由真实 Demo 与工作台 renderer 生成的参考预览，可通过 `python3 scripts/render_demo.py` 重建。README 的截图区域目前保留占位，待补充正式截图或动图。`xserial demo --snapshot` 是无需交互 TTY 的最短体验入口。

建议发布介绍：

> xserial 是终端里的二进制串口调试工作台。支持 Hex 收发、命令收藏、大小端字段解释、校验与分帧，以及原始双向录制和离线回放。运行 xserial demo，无需硬件即可体验一次完整的设备查询。

## 首批用户验证

尚未邀请或联系外部用户，也尚未获得真实设备反馈。建议先邀请 5 位串口与协议调试用户，记录以下结果：

| 场景 | 观察内容 |
| --- | --- |
| 安装与 Demo | 是否能独立完成体验，是否清楚如何退出 |
| 真实设备连接 | 平台、适配器、波特率、连接与重连表现 |
| 查询与响应解释 | 是否能找到字段，是否能理解大小端与 CRC |
| 修改后重发 | 输入、收藏和历史是否减少重复操作 |
| 保存并交给别人 | 同事是否能通过回放与导出理解问题 |

收集复现步骤、预期与实际行为；分享记录前由用户检查是否包含设备或业务敏感内容。发布后关注下载、真实使用案例、重复使用与最常展示的功能，Star 作为反馈之一。
