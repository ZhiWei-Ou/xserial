# TUI 需求

## 定位

TUI 是面向二进制串口数据收发的全屏终端。它帮助用户方便地输入 Hex 字节，并按时间顺序观察 TX/RX 数据。

TUI 不再承担文本 Shell 终端职责。需要文本、ANSI 或 Shell 交互时，应使用 [RawUI](rawui.md)。TUI 通过 [Middleware](middleware.md) 使用 [Backend](backend.md)。

## 启动

- 使用 `xserial <port> [baud] --tui` 进入 TUI。
- 连接成功后直接进入二进制界面，不再提供 Text/Hex 模式切换。
- 顶部始终显示端口、波特率、帧配置和连接状态。
- 连接状态至少区分 connected、disconnected、reconnecting、failed。

## 界面结构

```text
连接信息与 RX/TX 统计
┌──────────────────────────────────────────┐
│ 按时间排列的 TX/RX 二进制流量            │
│ 方向 · 时间 · 长度 · Hex · ASCII         │
└──────────────────────────────────────────┘
Hex 输入区 · 字节数 · 输入校验
操作状态
快捷键提示
```

- 终端缩放后所有固定区域仍可见，主流量区使用剩余空间。
- 小终端下优先保留方向、Hex 数据和输入状态；ASCII、时间等次要列可以收缩，但不能造成横向溢出。
- 流量历史与输入区不能相互覆盖。

## Hex 输入

### 接受的格式

用户可以键入或粘贴以下形式：

```text
AA 01 ff 00
AA01ff00
AA,01,ff,00
0xAA 0x01 0xff 0x00
```

- Hex 字母不区分大小写。
- 支持连续偶数位 Hex、空白分隔、逗号分隔和逐字节 `0x` 前缀。
- 不允许奇数位连续 Hex、超过一个字节的 `0x` 项或非 Hex 字符。
- 不对输入追加 CR、LF、NUL 或其他隐含字节。

### 编辑反馈

- 输入实时规范化为大写、空格分隔的形式，例如 `AA 01 FF 00`。
- 输入区持续显示当前有效字节数。
- 非法输入显示错误位置与原因，Enter 不发送。
- 空输入按 Enter 不发送，并提示没有可发送内容。
- 发送请求进行中时避免重复提交。
- 发送失败后保留原输入，用户可以修改并重试。

### 发送历史

- 成功提交的手工 Hex 输入进入当前会话历史。
- Up/Down 浏览上一条或下一条历史，并将其放回输入区编辑。
- 历史有内存上限，只在当前会话内保存，不写入配置文件。
- PageUp/PageDown 用于浏览流量历史，不再使用 Up/Down 滚动主区域。

## TX/RX 流量时间线

- TX 和 RX 在同一时间线中按实际发生顺序展示。
- 每个条目至少显示：方向、时间、字节数、Hex 和可打印 ASCII。
- 不可打印 ASCII 使用统一占位符，不执行控制字符。
- TUI 不解析 ANSI，不允许设备字节清屏、移动光标或改变主界面样式。
- 串口本身没有消息边界。接收条目只能称为数据块或接收事件，不能展示为已经解析的协议帧。
- 手工发送只有在 Backend 确认完整写入后才标记为成功 TX；失败在状态区显示并保留输入。
- 用户滚动离开底部后，新数据继续进入历史，但视图不自动跳到底部。
- 回到底部后恢复跟随最新流量。

## 历史与性能

- 流量历史使用明确的内存上限，同时限制条目数和累计字节数。
- 达到上限时从最旧的完整条目开始回收，不截断正在显示的条目。
- 高速接收时允许合并相邻的同方向显示更新以降低重绘频率，但必须保持字节顺序和总数，且不能声称合并结果是协议帧。
- RX/TX 统计反映实际成功接收和发送的字节数。
- 大量二进制数据不能导致输入明显失去响应或界面持续增长内存。

## Raw 文件发送

- Command Palette 提供 raw file send。
- 用户输入文件路径后确认发送；空路径或 Esc 取消。
- 发送期间 Middleware 独占 outbound，禁止手工 Hex 发送。
- RX 数据仍进入时间线。
- 流量区只保留一条文件操作摘要，显示文件名、总大小、进度和最终状态，不展开全部文件字节。
- Esc 取消正在进行的文件发送。
- raw file send 不提供校验、重传或断点续传。

## Command Palette 与按键

| 按键 | 行为 |
|---|---|
| `Ctrl-P` | 打开或关闭 Command Palette |
| `Ctrl-C` | 退出会话 |
| `Up` / `Down` | 浏览 Hex 发送历史 |
| `PageUp` / `PageDown` | 浏览流量历史 |
| `Esc` | 关闭面板、取消路径输入或取消文件发送 |
| `Enter` | 发送有效 Hex 或确认文件路径 |

Command Palette 第一阶段只包含：

- Send raw file；
- Clear traffic；
- Cancel transfer，仅在发送进行中可用；
- Quit。

不再包含 Text/Hex 切换或 YMODEM 上传、下载。

## 断线与退出

- 断线后状态区显示原因和重连进度，已经展示的流量历史保留。
- 重连期间禁止 Hex 和文件发送，不缓存待发送数据。
- 重连成功后继续当前界面和历史。
- 文件发送在断线时立即失败，重连后不自动恢复。
- 重连耗尽后显示最终错误并安全退出 alternate screen。
- 用户退出、取消和异常返回都必须恢复终端。

## 可用性与质量

- Hex parser、输入规范化、错误定位和历史浏览使用纯逻辑测试。
- 时间线测试覆盖 TX/RX 顺序、ASCII 安全展示、滚动保持、历史裁剪和高速数据更新。
- 文件发送测试覆盖进度摘要、手工发送互斥、取消、失败和断线。
- 布局测试覆盖常见终端尺寸、窄终端和 CJK 字符宽度。
- 并发测试不使用 sleep 推测 UI 或 Backend 状态。

## 本轮不包含

- Text/Shell 模式；
- ANSI 文本解释；
- YMODEM；
- 帧边界、长度字段或 CRC 模板；
- 协议字段解析器和外部协议插件；
- 完整展开大文件发送字节；
- 二进制流量记录文件格式。
