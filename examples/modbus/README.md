# Modbus Debugging Examples

This directory provides command favorites for normal queries, bad response CRCs, split responses, and joined responses, plus a bidirectional recording generated by an actual simulated query.

```bash
xserial demo --frame modbus-read --commands examples/modbus/commands.json
xserial replay examples/modbus/demo.xsr --frame modbus-read
xserial export examples/modbus/demo.xsr
```

Press Ctrl-O to select and load a favorite, then Enter to send it. Device address 1 returns normal data, address 2 deliberately corrupts the response CRC, address 3 returns the response across two reads, and address 4 joins two responses into one read. The request in the bad-CRC scenario still has a valid checksum so you can test response verification.

The normal response is `01 03 04 00 64 00 65 7B C7`. The two big-endian registers contain 100 and 101. See the [workbench guide](../../docs/workbench.md) for the complete walkthrough.
